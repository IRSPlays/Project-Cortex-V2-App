## 2024-05-23 - Critical Password Exposure in Logs
**Vulnerability:** Found `console.log` exposing user password in `src/app/caregiver-login/page.tsx` and `server.log` checked into the repo.
**Learning:** Developers sometimes leave debug logs that print sensitive state variables (like passwords or tokens) for convenience during development, forgetting to remove them before commit. Also, log files generated by the server were not ignored by git.
**Prevention:** Always review `console.log` statements before committing, especially in form handlers. Ensure all runtime log files are added to `.gitignore`. Use a logger that can be configured to strip sensitive data or disable logging in production.
