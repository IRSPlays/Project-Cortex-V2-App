# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do not report it through public GitHub issues.

### Procedure

1.  Please report vulnerabilities via email to the repository maintainers (e.g., security@example.com).
2.  Include details about the vulnerability, steps to reproduce, and potential impact.
3.  We will acknowledge your report and work to resolve the issue as quickly as possible.
